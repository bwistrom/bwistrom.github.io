# Chatula Workspace

A futuristic 3D workspace environment that combines the power of Chatula with an immersive 3D interface.

## Features

- **3D Environment**
  - Interactive 3D workspace with dynamic lighting and effects
  - Quantum particle system for visual feedback
  - Universal physics simulation
  - Infinite timeline visualization
  - Responsive camera controls with smooth transitions

- **UI Elements**
  - Modern, glass-morphic interface
  - Coordinate display system
  - Interactive control panel
  - Lucky clover feature
  - Dynamic window management

- **Technical Features**
  - Three.js for 3D rendering
  - GSAP for smooth animations
  - Custom shaders for visual effects
  - Responsive design
  - Performance optimized

## Project Structure

```
chatula-workspace/
├── index.html          # Main HTML file
├── style.css          # Global styles
├── script.js          # Main workspace logic
├── lucky-clover.js    # Lucky clover feature
└── README.md          # Project documentation
```

## Setup

1. Clone the repository
2. Open `index.html` in a modern web browser
3. Enjoy the immersive 3D workspace!

## Dependencies

- Three.js (r128)
- GSAP (3.7.1)
- OrbitControls
