# Command Center Environment

A 3D interactive command center environment built with Three.js.

## Features

- Interactive 3D environment with camera controls
- Real-time time display
- Coordinate tracking
- Quantum field visualization
- Neural network particle system
- Ambient particle effects
- Holographic displays
- Time sphere

## Controls

- 🖱️ Left-click and drag: Rotate view
- 🖱️ Right-click and drag: Pan
- 🖱️ Scroll: Zoom in/out
- ⌨️ WASD: Move camera
- ⌨️ Space/Shift: Move up/down

## Technical Details

- Built with Three.js r128
- Uses OrbitControls for camera manipulation
- Implements particle systems for visual effects
- Real-time coordinate tracking
- Responsive design

## Requirements

- Modern web browser with WebGL support
- Internet connection (for Three.js CDN)

## Usage

1. Open `commandcenter.html` in a web browser
2. Use mouse and keyboard controls to navigate
3. Observe the various visual effects and systems
