## 🚀 Navigation Guide

### Basic Controls
1. **Click to Travel**
   - Click anywhere in the environment to journey to that point
   - Smooth camera transitions will guide your path

2. **Personal Movement**
   - When within 70km of the grid:
     - Hold Ctrl + Double-click to initiate personal movement
     - Move your mouse to control direction and speed
     - Triple-click to release from movement mode

3. **View Controls**
   - Use the navigation menu on the left side
   - Access different perspectives:
     - Front View (⬅️)
     - Side View (➡️)
     - Top View (⬆️)
   - Toggle Grid visibility (📏)
